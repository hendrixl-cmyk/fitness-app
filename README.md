# Fitness Tracker

A single-page weekly fitness tracker. Open `index.html` in any browser — no install needed.

- **Workouts this week** — progress toward the 3-workout minimum
- **My workouts** — your workout list; check one off and pick the day you did it
- **Daily checklist** — Mon–Sun boxes for eating right, supplements, and 10K steps
- **Past weeks** — see which weeks you hit 3+ workouts (tap one to jump to it)

Data saves automatically in your browser. Use **Back up data** to download a copy and **Restore backup** to load it on another device.

To use it on your phone, enable GitHub Pages for this repo (Settings → Pages → deploy from branch) and add the page to your home screen.
